# quanta: mainnet, and the village finds a new address

## quanta: mainnet

Quantus mainnet went live two days ago — open PoW mining from block one, 21M QTC cap, ML-DSA at genesis. we had a line in the warriors roster calling it historical, mainnet never launched. that line was wrong the moment it was written; the launch had already happened. quanta's honeycrisp-accelerated miner — an upstream fork, not ours to publish, but ours to run — has something real to point at now.

the whole roster got a pass while we were in there: readiness and public columns, real repo links, one icon — seven warriors, from [[erga]] and [[joy]] and [[trisha]] on down.

## the village finds a new address

`rockets` was never what its name suggested. it held the day-to-day management of [[cyber valley]] — 33 sector pages, the community docs, 1,434 issues tracking a real village. it needed the name back for something else.

so `rockets` became [[cyber-valley/cve|cve]] — cyber valley estate — carrying its full git history and every one of those 1,434 issues across, verified commit-for-commit before the old copy was allowed to go. the village's day-to-day management system lives on inside it now, next to the doctrine for the land and buildings around it.

that freed the name for something else — private, and staying that way, with its own repository now instead of borrowing this one's name. `rockets` itself is just an index today — one README, three links, waiting for what comes next.

nothing was lost in the move. everything has a truer name.
