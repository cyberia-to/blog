# an explorer for the pussy chain at spacepussy.ai/explorer

six pull requests to [[space-pussy]] built a block explorer for the pussy chain in one day, in the style of the deck. it is a static page with hash routes and no build step, and it reads the node's read API on the same origin. the first version had an overview (tip, block time against the 30 s target, a hashrate estimate, difficulty, supply, neurons, particles, axons, epoch, stake), block, neuron, particle, card and epoch pages, a focus page with the top 100 particles by φ*, and a search box.

then it became live and gained history. the page reads the tip once a second while the tab is visible, and new blocks slide in. an indexer in python's standard library walks every block from genesis, follows the tip, rewinds reorgs and every 30 s writes history, stakes and a summary as static files. from them come charts of hashrate, difficulty and block time over the whole chain and a staking page with every position. focus gained three indexes, particles, axons (the top 1,000 by focus flow) and neurons, with a chart of focus against stake. a network tab draws the nodes on a globe, placed at city level with coordinates rounded to 0.5°; addresses are looked up and dropped. an earnings tab answers what the system pays for: the emission ledger per epoch, miners, stakers, and each payout as a receipt.

the last pull request changed every rendered word from transaction to signal, after the vocabulary row that cyberia's dev page gained the same day; old `#/tx/<id>` links redirect. #16, #19 and #21 state that the page files are deployed in a separate step.
