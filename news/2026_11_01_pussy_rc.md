# pussy-rc: a rehearsal chain built from pussy's burial state

the rehearsal stand got a genesis of its own. `soft3 genesis build --chain pussy-rc` builds pussy's real burial state from the same snapshot with the same derivation, under the name pussy-rc. the `hrp` and the native denom stay `pussy`, so legacy owners, balances and the native token match pussy's and the same keys work. the name sits inside the hashed file, so the particle of the file, which is the chain id, differs from pussy's, and the two chains cannot be mistaken for each other. pussy-rc has no blessed time, so the build refuses to run without `--time`. the first time is pinned as 1793523600, 2026-11-01T09:00:00Z, and restarting the rehearsal is a one-line pull request.

the release gate `stack-chain-genesis` builds `pussy-rc.tade` beside pussy's file on every train run, verifies it and publishes it with its sha256. a second pull request pinned the bytes: the gate is red when the file it builds differs from the published one. the pinned file is 3249660 bytes, and its state root equals pussy's, as it must for the same burial state under another name. 4 new tests cover the pin. both pull requests merged into `release/phase1` of [[soft3]].
