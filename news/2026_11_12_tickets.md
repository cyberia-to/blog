# the alpha network mines by tickets, and the explorer reads them

the alpha rehearsal network pussy-rc restarted from block 0 on 2026-11-12 at 16:29 UTC with the settlement ticket as its proof of work, on its two hosts. the chain it replaced, 32,519 blocks of hash proof of work since 2026-11-01, is kept beside it. this is settlement mining from the rewards specification of [[tru]], §7–§8: each mining attempt is one Shapley sample, the winning ticket is the block's work and takes its subsidy, and every node verifies it by recomputing it. the node side is [[cybernode]] #18 on the branch `feat/ticket-pow`, a pull request against `release/phase1`, and the receipt of the redeploy is a file on that branch.

[[space-pussy]] #23, merged into main, taught the explorer to read tickets. the header is 200 bytes with the sample at offset 168, and the settlement record is 218 bytes. the indexer reads the sample of every block, the game that each epoch's window samples and the lottery of every settled epoch, and writes `tickets.json`: attempts per block = 2^256/(target+1), and tickets per second as the sum of attempts over the elapsed time. the block page shows its ticket, the epoch page the lottery table, and the overview's hashrate tile became tickets/s. the work is detected once, from the indexer's summary or the length of the genesis header, so a chain on hash proof of work reads as before.

the plan pull request soft3 #685, merged into `release/phase1`, records the alpha as redeployed on ticket proof of work from block 0 and the explorer change as deployed.
