# contribute

every page on cyberia.blog lives in a repository of [cyberia-to](https://github.com/cyberia-to): fork it, edit the `.md`, open a pull request. the page footer names the repository a page comes from.

the four ways in — pull requests, linking on the live net, running a node, building a component — are written once, at [[cyber/contribute]].
